El diseño de la solución propone el desarrollo de un sistema integral de gestión contable y facturación automatizada orientado a pequeñas y medianas empresas proveedoras de servicios de internet (ISP) en Colombia. La solución tecnológica tiene como finalidad integrar y automatizar los procesos administrativos, financieros y contables dentro de una sola plataforma, permitiendo optimizar la gestión empresarial y mejorar la eficiencia operativa.
El sistema será desarrollado bajo una arquitectura web cliente-servidor utilizando Oracle Database como motor de base de datos y Oracle APEX como herramienta de desarrollo web. Esta arquitectura permitirá que los usuarios accedan al sistema mediante navegador web, facilitando la administración centralizada de la información y garantizando disponibilidad, escalabilidad y seguridad de la información.
La solución se construirá tomando como base la estructura de la base de datos diseñada para la empresa de telecomunicaciones, conformada por las tablas CLIENTE, FACTURA, PAGO, CUENTA_PUC, TRANSACCION, MOVIMIENTO e INFRAESTRUCTURA.
